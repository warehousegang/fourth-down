# Data inventory and provenance
Checked 2026-10-24. Primary input: [nflverse schedules](https://github.com/nflverse/nflverse-data/releases/tag/schedules), originating with [Lee Sharpe / nfldata](https://github.com/nflverse/nfldata). Access via nflreadpy 0.1.5. [Schedule dictionary](https://nflreadr.nflverse.com/articles/dictionary_schedules.html).

Use 2010–2023 regular-season schedule rows. Required fields: game_id, season, week, game_type, gameday, gametime, home_team, away_team, home_score, away_score; stadium/location optional. No market odds, postgame statistics, injuries or news enter predictors. Scheduled kickoff and stadium are display metadata. Score-derived fields use only earlier game dates. Season and team identifiers index records. Ties update history at half a win, but are excluded as binary evaluation targets. Missing outcomes never update history.

The nflreadpy loader retrieves an all-season upstream asset, then filters. Acquisition immediately selects approved seasons/columns before local persistence, feature generation, summaries, or evaluation; the current pipeline does not analyze protected seasons. The original legacy baseline ran previously and its aggregate results were observed; see HOLDOUT_EXPOSURE.json. No additional holdout data was acquired or inspected during correction. This is not physical upstream byte isolation. Raw selected snapshot and manifest are local/ignored. Record SHA256, extraction time, package versions, rows and coverage in the manifest. No automatic refresh. A later source correction can change reproduction; use the captured snapshot for exact reruns.

[nflverse-data declares CC BY 4.0](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md). Attribute nflverse and Lee Sharpe; link the source/license and identify derived features and predictions as modifications. The upstream nfldata repository does not display a separate license in its root listing. Repository licensing does not settle every upstream or trademark right. Public redistribution needs owner review at G3. The prior reskin's NFL/ESPN PNGs were retired from public assets and are not tracked or distributed. TEAM_ASSETS.json retains historical source/checksum provenance and records retirement. Original CSS team abbreviations now identify matchups. Dependency notices are separate from the schedule license; see THIRD_PARTY.md. Not affiliated with the NFL or nflverse. No FTN/PFR/PBP data is used.

Freshness limitation: schedules are a current corrected historical extract, not archived as-of snapshots. Historical availability is a model assumption, not proof of the publisher's release time. Show retrospective labels throughout. Future injury/news/weather inputs need separate terms, source timestamps and review.
