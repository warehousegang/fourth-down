# Schedule intelligence challenger — predeclared local experiment

Protocol version `schedule-intelligence-v1`, declared 2026-10-24 before the first fit in this implementation. This is a separately versioned research challenger. It cannot replace the frozen incumbent or generate current operational probabilities. The existing 2023 selection history is preserved; every 2023 result here is a selection-exposed retrospective diagnostic, never an untouched test. No 2024 or 2025 input may be read, including 2025 prior-season strength for a 2026 challenger forecast.

## Dataset and eligibility

Use only the existing hash-verified nflverse 2010–2023 regular-season CSV (SHA256 `20f573837dac7d9ea41dade07b165de6164b3370d60e49d5242e5255cabb7d01`). No downloads. 2010 is prior-season warmup; labeled examples start in 2011. Binary outcomes exclude ties but ties update history by half a win. All features are computed from strictly earlier calendar dates, with same-date batches updated together. The snapshot is a corrected historical extract without publication-vintage evidence; this remains retrospective analysis. Preserve team franchise continuity for STL→LA, SD→LAC, OAK→LV. Missing prior-season team history excludes the row; it is never fabricated as neutral strength. Missing preceding outcomes makes the feature row unavailable. Week 1's current-season state uses the incumbent's documented symmetric shrinkage, while prior-season values are real recorded completed games.

## Exact fixed features

The four incumbent definitions remain unchanged: smoothed current-season wins `(wins+2)/(games+4)`, scoring margin `sum(margins)/(games+4)`, recent margin `sum(last five)/(min(5,games)+2)`, rest `min(14,days since last game)` or seven before the first game. Home minus away differences enter the challenger.

Add six features: previous-season smoothed-win difference; previous-season shrunk-margin difference; opponent-adjusted margin difference (each completed game's own margin plus its opponent's *pregame*, earlier-date shrunk margin, averaged with four zero-margin prior games); venue-role margin difference (home team's prior non-neutral home margins minus away team's prior non-neutral road margins, each shrunk with four zero-margin games); bye difference (prior game exists and elapsed calendar days ≥12); neutral-site indicator. No travel-distance, quarterback, player, injury, weather, play-by-play efficiency, or news feature is included. These remain inventory and timestamp-contract work, not claimed predictive capability.

## Estimator and calibration

Single configuration only; no grid search or post-result tuning. StandardScaler fit solely on training rows; logistic regression L2 C=1, solver=lbfgs, max_iter=2000, random_state=42, no class weights. Export raw coefficients plus the training means/scales. Platt calibration fits a one-input logistic regression to raw log-odds on the immediately following calibration season, C=1,000,000, same solver/seed/max_iter. Threshold=0.5, conditional on a non-tied result. Calibration data is never used for the base model or feature-scaling fit. The same deterministic calibration procedure is used in all challenger ablations. Do not choose raw versus calibrated results after seeing a diagnostic: calibrated is the predeclared primary challenger. Export both to show calibration's effect.

## Time-aware evaluation

For diagnostic seasons 2018 through 2023, train 2011 through season−2, calibrate on season−1, then evaluate season. The final research model is the 2023 fold: base fit 2011–2021, calibration 2022, diagnostic 2023. Do not refit on 2023. Report per-season and pooled accuracy/Brier/log loss, calibration bins, and counts. Baselines: constant .5 and training-set home-win frequency. For every rolling fold, fit an uncalibrated *incumbent recipe* (four unchanged features, StandardScaler, C=1) on the same base training period; label it a refitted comparator, not the frozen incumbent. Separately score the actual frozen incumbent on 2023 only, where it is out of its 2010–2022 fitting period; its longer training window means this is not a controlled feature-only comparison. Never score the frozen incumbent on its own historical training seasons as if that were backtest evidence.

Measure each implemented domain by retraining a fixed-config model omitting that domain's assigned feature group; independently calibrate on the same calibration slice and report full-minus-ablated Brier (negative favors the full model). Report all ablations, including harmful or null ones; do not use them to edit features or select a winner. Unimplemented domains have contribution=null, reason=not measured. These correlated-domain ablations do not establish causality.

Uncertainty: seed42, 2,000 paired bootstrap replicates over whole `(season, week)` blocks. Pooled comparisons stratify by season and resample its observed week blocks with replacement; each game's paired scores remain together. Report percentile95% intervals for Brier differences, the block unit, and replicates. 2023 uses its season-week blocks. Game-level independence is not assumed; repeated-team dependence across weeks may still make intervals optimistic.

## Availability contract for future enrichment

Evidence must include domain, game/team identity, source URL, provenance checksum, publication/observation/retrieval timestamps, validity horizon, explicit source/license approval, and structured value. At the prediction cutoff require all timestamps ≤cutoff, observation before cutoff, non-stale validity, matching identities, and a verified status. Reject target/postgame evidence, conflicting claims, unconfirmed starters, retrospective observed weather, and news about private mental states. Source text is data, not executable instructions. This adapter only returns eligible annotations; it cannot alter coefficients or probabilities. Real extraction and contribution experiments require an approved vintage dataset and another protocol version.

## Promotion and rollback contract

No automatic promotion. A candidate must have complete reproducible provenance and point-in-time evidence for all its operational inputs, live availability without protected-season consumption, passed regression/security/static-contract tests, acceptable calibration (pooled ECE≤0.05 and no season >0.10), pooled Brier improvement ≥0.002 over the contemporaneously refitted incumbent recipe with paired95% upper bound <0, and no per-season Brier regression >0.01. ECE uses fixed ten probability bins and is diagnostic, not a guarantee. These thresholds are predeclared for review only and cannot unlock the partially exposed 2024–2025 holdout. Evidence from already observed 2018–2023 alone cannot justify production promotion; prospective shadow evaluation with at least one full season and a separately approved protocol is required. Owner approval must name candidate ID, artifact SHA, evaluation evidence and effective time. Before approval, registry operational_model_id remains `schedule-v1-741cf41752` and challenger operational_status remains ineligible. Rollback restores an approved prior registry/model/artifact SHA without rewriting forecast history. Newly completed seasons can be added only through a new approved dataset/protocol version; no automatic training after an incorrect prediction.

## Execution

`python -m ml.challenger` performs this authorized, local, non-holdout experiment and writes content-addressed research artifacts. It never imports the historical training entry point or overwrites frozen artifacts. The release test runner continues to prohibit fits; challenger tests verify saved models, feature timing and evidence controls without fitting. A dedicated opt-in `--verify-repeat` run repeats the fixed experiment and asserts equality excluding run timestamps. Training is explicitly authorized by the 2026-10-24 product directive, and limited to this separate pipeline.
