# Third-party attribution and notices

Corrective review date: 2026-10-24. Full bundled notices ship in `web/public/THIRD_PARTY_NOTICES.txt`, are linked from every dashboard screen, and are copied byte-for-byte into the static build. `npm run notices` generates them from the exact package-lock versions and installed LICENSE files; every build checks completeness and rejects stale output. The five production packages are lucide-react 0.468.0 (ISC plus its included Feather MIT attribution), react 19.3.1, react-dom 19.3.1, scheduler 0.28.0 and zod 4.6.7 (MIT). No new dependency was added.

`PYTHON_DEPENDENCY_NOTICES.txt` preserves complete installed license/notice files for all 41 pinned Python distributions; `PYTHON_DEPENDENCY_LICENSES.json` records versions, source paths and SHA256 hashes. Reproduce with `python scripts/generate_python_notices.py --check` in the existing matching environment. nflreadpy's installed distribution omitted its full license, so the MIT text was retrieved from the official [v0.1.5 revision](https://github.com/nflverse/nflreadpy/blob/95b6cb50852523d043b8bf3abc62e801a3654b7d/LICENSE.md) and preserved under docs/licenses/. Python binaries and packages are not bundled in the source or static site. Future binary redistribution would require a separate review of source and other license obligations.

The dashboard and notices retain **nflverse schedules / Lee Sharpe**, source links, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and the statement that features and predictions are derived modifications. The [nflverse-data license](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md) was checked again. Use is based on the documented public repository license with source attribution and derived-work labeling. This portfolio ships no official NFL imagery and claims no endorsement.

All 32 ESPN-hosted team PNGs were removed from public assets and excluded from Git and dist. Historical URLs and hashes remain in TEAM_ASSETS.json, explicitly marked retired. An ignored local artifacts/retired-team-logos/ directory preserves the previous files only; it is not a release input. Matchups now display original CSS text identifiers. No official team mark or third-party font is shipped. Lucide UI icons are covered by the bundled notices.

Project source now has a root MIT LICENSE, copyright Thomas Howard. Third-party data and dependencies retain their documented terms; this license does not grant NFL mark rights. Public publication still awaits the owner’s explicit approval.

## Product execution context addition
The current-context artifact derives selected weekly injury reports, QB depth-chart rows and basic team statistics from season-isolated 2026 [nflverse-data releases](https://github.com/nflverse/nflverse-data/releases). Each artifact retains exact source URLs, SHA256, capture/update times, nflverse attribution and the repository [CC BY 4.0 license reference](https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md). The UI identifies the derivation and links nflverse and CC BY 4.0. No claim of confirmed starter status, complete injury health coverage or rights to NFL marks is made. These context-only transformations do not change model probabilities. Historical Lee Sharpe schedule attribution remains distinct. No new logo/font asset or dependency was added. The current public-data terms and notices are retained for this educational portfolio.
