# Evaluation protocol v1
Training: 2010–2022. Validation: 2023. Protected final holdout: 2024–2025, not evaluated or tuned. Holdout evaluation has no executable path in this local build. Original baseline.py is preserved but unsafe to run under this gate because it scores the holdout. Original train.py is reproduced via its exact feature function and LogisticRegression(max_iter=1000) against restricted input.

Compare 50/50, training home-win frequency, original unsmoothed win-percentage logistic regression, and one standardized L2 logistic candidate (C=1, seed=42, max_iter=1000). Candidate inputs: smoothed season win-rate difference, shrunk season point-margin difference, shrunk last-five point-margin difference, capped rest-day difference. Also evaluate predeclared leave-one-feature-out ablations; do not use them to create a second tuned candidate. Select the simplest contender within 0.001 Brier of the best; publish all comparisons. No search over hyperparameters.

All probability predictions use identical non-tied validation rows. Metrics: accuracy at p>=0.5, Brier (primary), log loss, fixed ten-bin calibration with counts, and validation season summary. Historical backtesting: expanding training windows ending 2017–2021; assess 2018–2022 with the selected fixed definition, noting architecture selection used 2023. Resample validation paired Brier differences by week with seed 42 for a descriptive bootstrap interval; one season, dependence and model selection limit inference.

No held-out result enters its own features. New features update after an entire calendar day. Records reset per season. Train-only scaling. A prior game outcome can inform later validation games, but model parameters stay frozen. Do not interpret factors causally. Regularization and smoothing are fixed upfront, not optimized. Live injuries, quarterbacks, weather and play efficiency are omitted. Do not claim calibrated probabilities from a small reliability plot. Quantify early-season fallback and report failures honestly.

Freeze the selected model, source hash, feature spec, metrics and protocol before requesting holdout approval. Do not convert this document or a command flag into human approval.
